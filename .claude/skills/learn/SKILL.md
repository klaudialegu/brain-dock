   - Why it exists (the problem it solves)
   - An everyday analogy
   - How it works, 3-5 sentences, no jargon left unexplained
   - Where it shows up in this project (file path)
2. Append to docs/LEARNING_LOG.md:

### <Concept> (<YYYY-MM-DD>)
**One-liner:** ...
**Analogy:** ...
**In this project:** ...
**Interview-ready sentence:** how Klaudia could explain it in an interview, first person, plain words.

3. If the concept is already logged, add a "Revisited: <date>, <what's new>" line instead of a duplicate.
